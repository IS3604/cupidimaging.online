# Cupid Imaging LLC website

Static site, no build step. Upload the whole folder to any host (GitHub Pages, Netlify, cPanel).

- `index.html` page content
- `css/styles.css` all styles (desktop first, then tablet and phone sections)
- `js/main.js` services list, filters, form, menu and tabs
- `images/hero.webp` landing page photo

To change prices or the contact email, edit `SERVICES` and `CONTACT_EMAIL` at the top of `js/main.js`.
